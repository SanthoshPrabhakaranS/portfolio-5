# Santhosh Prabhakaran — Portfolio

Personal portfolio built with Next.js 15 (App Router) and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All content (profile, stats, projects, experience, tools, posts) lives in `src/data/data.ts`.
Project screenshots go in `public/projects/`. To show a profile photo, add it to `public/` and set `PROFILE.photo`.

## Deploy

Import the repo on [Vercel](https://vercel.com/new); no configuration needed.
